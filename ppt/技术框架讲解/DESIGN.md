# DESIGN.md — 技术框架讲解（深色工程风）

## 1. 画布与母版

- 画布 1280×720。安全边距：左右 56，上下 24。
- A 标题块：y 24–104（高 80）。左对齐主标题 34px Bold；右侧 mono 小标签（章节号）。
- B 内容区：y 112–648（高 536）。
- C 页脚：y 656–696。左侧 `fusion v3.8 / v3.9.1` 12px mono 灰；右侧 `NN / 16` 12px mono。
- 内容页统一：A 区标题 + B 区内容 + C 区页码。封面/章节扉页/结束页可省略母版。

## 2. 色彩系统（4 hex + 中性）

| 角色 | hex | 用途 |
|---|---|---|
| 背景 | `#0B1220` | 全页背景 |
| 面板 | `#121E33` | 卡片/容器底 |
| 主色 | `#38BDF8` | 主蓝（标题强调、图主线） |
| 辅色 | `#34D399` | 数据/成功/确定性标识 |
| 警示 | `#FBBF24` | 注意/边界（≤5%） |
| 文本主 | `#E6EDF7` | 标题、正文重点 |
| 文本副 | `#9FB0C8` | 正文、说明 |
| 文本弱 | `#6B7C96` | 脚注、页码 |
| 描边 | `#22314A` | 卡片描边、分割线 |

色彩面积：背景 55–65%，面板 20–30%，主蓝 ≤10%，绿+黄 ≤5%。Hero 页允许主蓝到 15%。
渐变：仅用于封面/章节扉页背景，`linear-gradient(135deg, #0B1220 0%, #10203A 100%)`。
半透明：图表底 `rgba(56,189,248,0.06)`，标签底 `rgba(52,211,153,0.10)`。

## 3. 字体

- 中文/正文：微软雅黑（Microsoft YaHei）。标题 600–700，正文 400。
- 数字/标签/代码：Consolas。全篇仅此两套。
- 层级：封面主标 64–72 Bold / 页面主标 34 Bold / 卡片小标 22 Bold / 正文 18–20
  / mono 标签 12–13 letterSpacing 1 / 巨型数字 72–96 Bold mono / 页脚 12。
- 正文行高 1.55；标签大写英文 + letterSpacing。

## 4. 版式与组件

- 主结构：`Slide`（背景 #0B1220，padding 上下 24 左右 56）+ 页脚绝对定位。
- 卡片：`background:#121E33`，`border:1px solid #22314A`，`borderRadius:10`，padding 20。
- 流程/架构图：内联 SVG（stroke `#38BDF8`，节点底 `#121E33`，确定性节点用绿描边）。
- 代码示例：CodeBlock `github-dark`，仅 1 页使用（数据模型页的 JSON 示例）。
- 数字锚点：mono Bold，主蓝或绿；每个内容页至少 1 个 ≥44px 元素或 ≥40% 面积的图。
- 表格：表头 `#16263F`，行分割 `#22314A`，正文 16–18。

## 6. 配图策略

- 全篇 L1 均为**结构图（SVG）**：架构图、双时间轴、写入流程、查询流程、one-hop 图。
- 不使用摄影/生图——技术架构页用结构化图示更准确，且与本系统「可审计」的调性一致。
- L3：页脚 mono 标签、章节号。

## 7. 硬约束

- 单页元素总高 ≤ 696（含页脚），B 区不溢出。
- 相邻页版式不重复；非对称版式 ≥ 40%（05/07/08/09/11/12/13/14 已满足）。
- 正文 ≥18px，卡片小标 ≥22px。
- 所有数字与结论来自 docs/framework-explained.md 与 README（多运行口径）。
